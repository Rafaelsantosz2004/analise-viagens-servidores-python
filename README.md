# Análise de Viagens de Servidores Públicos com Python

Este projeto realiza uma análise de dados sobre viagens a serviço de servidores públicos utilizando dados do **Portal da Transparência do Governo Federal**.

O objetivo foi aplicar conceitos de **análise e tratamento de dados com Python**, gerando métricas e visualizações a partir de dados reais.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib

## Etapas da análise

Durante o projeto foram realizadas as seguintes etapas:

- Leitura de dados em formato CSV
- Tratamento e limpeza de dados
- Criação de novas métricas (despesas totais e duração das viagens)
- Agrupamento e agregação de dados por cargo
- Geração de tabela consolidada
- Criação de visualização gráfica

## Resultados

A análise permitiu identificar:

- Cargos com maior número de viagens
- Média de despesas por cargo
- Duração média das viagens
- Destinos mais frequentes

Os resultados foram exportados em:

- Planilha Excel com os dados consolidados
- Gráfico de visualização das viagens por cargo

## Fonte dos dados

Portal da Transparência do Governo Federal:

https://portaldatransparencia.gov.br/
